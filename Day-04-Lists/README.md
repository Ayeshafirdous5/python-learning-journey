### Part 2 - List Methods
Learned how to work with and modify lists using different built-in methods.

### Topics Practiced

- `append()` - Adding an item to the end of a list
- `insert()` - Adding an item at a specific index
- `extend()` - Adding multiple items to a list
- `remove()` - Removing an item by its value
- `pop()` - Removing an item using its index
- `sort()` - Sorting list items
- `count()` - Counting occurrences of an item
- `index()` - Finding the position of an item
